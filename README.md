# 🚜 歡樂農場尋寶記 — HW1 Grid Map Value Iteration

以農場為主題的互動式網格地圖，透過 **Value Iteration（價值迭代）** 演算法，幫助牽引機找出回到溫暖小屋的最佳路徑。

---

## 📋 作業需求

| 項目 | 說明 |
|------|------|
開發 n×n 互動網格地圖，支援起點 / 終點 / 障礙物設定 |

顯示隨機初始策略（箭頭），並使用 Value Iteration 計算最佳 V(s) 及最優策略 |

---

## 🌟 功能說明

### 網格地圖設定
- 可選擇網格大小 **n = 3 ~ 9**，產生 n×n 的農場地圖
- 最多可放置 **n−2 個樹木障礙物**

### 滑鼠點擊互動
點擊方格會依序切換以下狀態，並**即時更新顏色**：

| 點擊順序 | 圖示 | 說明 |
|----------|------|------|
| 第 1 格 | 🚜 | **起點**（牽引機出發位置） |
| 第 2 格 | 🏡 | **終點**（溫暖小屋） |
| 第 3 格以後 | 🌳 | **障礙物**（樹木，最多 n−2 棵） |
| 再次點擊已設定的格子 | 🌾 | **取消**該格設定 |

### 初始策略展示
每個空白方格會顯示隨機產生的行動箭頭（↑ ↓ ← →）作為初始策略。

### Value Iteration 計算
按下「✨ 開始導航！」後：
1. 對每個非障礙、非終點的格子，反覆更新狀態價值 V(s)
2. 收斂後展示各格的 **最佳動作箭頭** 與對應的 **狀態價值（保留兩位小數）**

---

## 🧮 Value Iteration 演算法

$$
V(s) \leftarrow \max_{a \in A} \left[ R(s, a, s') + \gamma \cdot V(s') \right]
$$

| 參數 | 值 | 說明 |
|------|----|------|
| 折扣因子 γ | `0.9` | 未來獎勵的折扣率 |
| 收斂閾值 θ | `1e-4` | 當 max ΔV < θ 時停止迭代 |
| 移動獎勵 | `-1` | 每走一步扣 1 分 |
| 到達終點 | `0` | 到達目標獎勵為 0 |
| 碰牆 / 障礙 | 原地不動 | 無效動作維持在原格 |

## 🎮 操作流程

```
1. 選擇農場大小 n（5～9）
        ↓
2. 點擊第一個格子 → 設定 🚜 起點
        ↓
3. 點擊第二個格子 → 設定 🏡 終點
        ↓
4. 繼續點擊其他格子 → 種植 🌳 樹木（最多 n−2 棵）
        ↓
5. 按下「✨ 開始導航！」→ 執行 Value Iteration
        ↓
6. 地圖顯示每格的最佳方向箭頭與狀態價值 V(s)
```
